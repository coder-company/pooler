Management session

Enter the management secret configured under management.auth.secret. Pooler adds the Bearer scheme when it sends the Authorization header, so enter only the secret value, without the Bearer prefix. The secret is held in memory for this tab only and is never stored or sent anywhere except this listener. Leave it empty when this loopback listener permits anonymous read-only access.
